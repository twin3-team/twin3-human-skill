# twin3-human

> **Retired (2026-10-30):** the `human.twin3.ai` service has been retired and no longer resolves. This plugin and skill are withdrawn from all listings. Do not install or invoke them.

This repository is kept as a historical record only. It no longer publishes an installable plugin, registers no skills, and advertises no callable endpoint.

## What it was

A humanity-verification skill for [OKX OnchainOS](https://web3.okx.com/onchainos) / Agentic Wallet that answered "is this wallet a real person?" for any EVM address, with per-method ZK-style verification checks, paid per query with USD₮0 on X Layer. It was backed by **141,871 [Twin Matrix](https://twin3.ai) Soulbound Tokens** on BNB Chain plus the canonical Twin3 humanity registry.
